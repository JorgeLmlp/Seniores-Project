QUICK START:
  1. Update .env with your desired credentials (use .env.example as reference)
  2. Run: docker compose up -d
  3. Access: http://localhost:5001

SERVICES:
  - Flask API:   http://localhost:5001
  - MySQL:       localhost:3306
  - MySQL UI:    phpmyadmin (optional, not in compose)

COMMANDS:
  docker compose up -d       - Start stack
  docker compose down        - Stop stack
  docker compose down -v     - Stop and remove volumes
  docker compose logs -f     - Follow logs
  docker compose logs app    - App logs only
  ./start.sh                 - Automated startup script

ENVIRONMENT:
  The stack reads from .env file which is loaded by docker-compose.yml
  All credentials should be changed in production
  SECRET_KEY should be a strong random string in production

DATABASE INITIALIZATION:
  Tables are created automatically via db.create_all() in extensions.py
  No migrations setup required for basic use
  For production, consider using Alembic for migrations

PRODUCTION NOTES:
  - Use a proper WSGI server (gunicorn, waitress) instead of Flask dev server
  - Set FLASK_ENV=production
  - Change all default credentials
  - Use strong SECRET_KEY
  - Add reverse proxy (nginx)
  - Enable HTTPS
  - Set DEBUG=0
