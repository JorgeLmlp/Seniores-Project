=== ESTRUTURA DE PASTAS - DOCKER ===

Projeto Organizado:
├── docker/                          ← PASTA COM TUDO DO DOCKER
│   ├── Dockerfile                   ← Imagem do container
│   ├── docker-compose.yml           ← Produção (porta 5001)
│   ├── docker-compose.dev.yml       ← Desenvolvimento (porta 5000)
│   ├── docker-entrypoint.sh         ← Script de inicialização
│   ├── .dockerignore                ← Arquivos a ignorar no build
│   ├── .env                         ← Variáveis de ambiente
│   └── .env.example                 ← Template (seguro para git)
│
├── .env                             ← Cópia para compatibilidade
├── .gitignore                       ← Ignora .env do git
├── start.sh                         ← Script para rodar containers
│
├── app.py                           ← Código Python
├── extensions.py
├── requirements.txt
├── controllers/
├── models/
├── routes/
└── services/

COMO USAR:

1. RODAR CONTAINERS (Produção):
   docker compose -f docker/docker-compose.yml up -d

2. RODAR CONTAINERS (Desenvolvimento):
   docker compose -f docker/docker-compose.dev.yml up -d

3. USAR O SCRIPT:
   ./start.sh

4. PARAR:
   docker compose -f docker/docker-compose.yml down

5. VER LOGS:
   docker compose -f docker/docker-compose.yml logs -f

CREDENCIAIS:
   .env no docker/

PORTAS:
   Produção: http://localhost:5001
   Dev: http://localhost:5000
   MySQL: localhost:3306
